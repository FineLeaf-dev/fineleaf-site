FineLeaf파인리프

AI 에이전트로 소프트웨어 개발과 지식 작업을 자동화합니다

FineLeaf(파인리프)는 한국의 1인 IT 회사입니다. 사람이 단계마다 확인하고 승인하는 방식으로, AI 에이전트가 실제 업무를 끝까지 처리하는 도구를 만듭니다.

FineLeaf is a one-person software studio in Korea. We build tools where AI agents carry software and knowledge work through to completion, with a human approving each step.

Products

  • Leafier

    자연어로 요청하면 소프트웨어를 만들어 주는 서비스

    요청을 문서로 정리하고, 그 문서에서 프로젝트 뼈대를 만들고, 기능을 하나씩 구현합니다. 각 단계의 결과는 사람이 검토한 뒤에 다음 단계로 넘어갑니다.

  • Leafroot

    지식 관리 시스템

    글과 영상, 메모를 한 가지 주장만 담은 노트로 정리하고 노트끼리 연결합니다. 쌓인 지식은 에이전트가 일할 때 참고 자료로 쓰입니다.

  • LeafFire

    한국형 FIRE 플래너 미니앱

    절세 계좌와 배당을 기준으로 은퇴 시점과 필요한 자산을 계산해 주는 재테크 계산 도구입니다.

How we build

FineLeaf의 제품은 Claude Code로 개발합니다. 설계와 구현, 검토를 AI 에이전트와 함께 진행하고, 결정과 승인은 사람이 맡습니다.

에이전트가 만든 결과물은 제안으로 다룹니다. 사람이 확인하기 전에는 다음 단계로 넘어가지 않는다는 원칙을 제품에도 그대로 넣었습니다.
